# Sprint 0-3 Report
Here is a report on the progress of project FitPro during Sprint 1.

## What Is Working
On the customer side we have:
- A professional looking main page for the FitPro app which is not connected to anything (https://fitpro.rockymountaintechlab.com/)
- A users page that lists test data that demonstrates the user model we created (https://fitpro.rockymountaintechlab.com/users/)

On the backend we have:
- a project than can be run locally by all team members
- the user model and its migration
- a rudimentary automated passing test

## Struggles Encountered
1. Learning collaborative tools. Most of us had never worked on a project this large, and GitHub had a steep learning curve. We knew how to push and pull, but managing pull requests, merging teammates' changes, and tracking edits across files took time to learn, so simple tasks took longer than expected.

2. New technologies. We worked with unfamiliar languages and concepts, including databases and login and registration features. Relying on AI to get started made it harder to fully understand how things worked, which made troubleshooting more difficult.

3. Cloud setup, cost, and security. We had to choose a hosting option within a limited trial budget, and unexpected charges and quotas got in the way. Setting up secure access was complex and needed careful testing, and our first deployment took several rounds of debugging.

4. Scheduling. With busy schedules outside of class, it was hard to find times to meet, which made it harder to combine our work and stay organized.
